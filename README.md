# JavaScript 까다로운 개념 학습 가이드

자바스크립트를 배우면서 많은 개발자들이 어려워하는 까다로운 개념들을 체계적으로 학습하기 위한 저장소입니다.

## 📚 학습 목차

### [01. 클로저 (Closures)](./01-closures)
함수가 선언될 때의 렉시컬 환경을 기억하여 외부 함수의 변수에 접근할 수 있는 개념

### [02. this 바인딩 (this Binding)](./02-this-binding)
컨텍스트에 따라 달라지는 `this`의 동작 방식

### [03. 프로토타입 (Prototype)](./03-prototype)
자바스크립트의 상속 메커니즘과 프로토타입 체인

### [04. 비동기 처리 (Asynchronous)](./04-async)
콜백, Promise, async/await를 통한 비동기 프로그래밍

### [05. 호이스팅 (Hoisting)](./05-hoisting)
변수와 함수 선언이 스코프 최상단으로 끌어올려지는 동작

### [06. 스코프 (Scope)](./06-scope)
전역, 함수, 블록 스코프와 스코프 체인

### [07. 이벤트 루프 (Event Loop)](./07-event-loop)
자바스크립트의 동시성 모델과 비동기 실행 메커니즘

### [08. 참조 vs 값 (Reference vs Value)](./08-reference-vs-value)
원시 타입과 참조 타입의 전달 방식 차이

### [09. 실행 컨텍스트 (Execution Context)](./09-execution-context)
코드가 실행되는 환경과 컨텍스트 구성 요소

### [10. 동등 비교 (Equality)](./10-equality)
느슨한 동등 비교(==)와 엄격한 동등 비교(===)의 차이

### [11. Promise와 async/await](./11-promise-async-await)
Promise 기반 비동기 처리와 async/await 문법

## 🚀 사용 방법
